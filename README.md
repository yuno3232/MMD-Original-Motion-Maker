# MMDオリジナルモーションメーカー
まだ開発途中で全然できてないです

ブラウザ上でベースモーションを生成し、MMD用の `.vmd` ファイルとして保存できる試作ツールです。
完成された振付ではなく、あとから編集するための「土台」となる動きを作ります。


## 使い方

1. ページを開きます。
2. 曲の長さ、BPM、スタイル、動きの大きさを設定します。
3. 「VMDを生成して保存」を押します。
4. 保存した `.vmd` をMMDに読み込み、モデルに合わせて動きを確認・調整します。


## 注意事項

- 試作版のため、生成されるのはベースモーションです。仕上げはMMD上で行ってください。
- モデルごとにボーン名や構造が異なるため、すべてのモデルで同じ動きになるとは限りません。
- 足IKやモデル固有ボーンの自動調整には対応していません。
- 実際に使う前に、必ずMMDで動作を確認してください。


公開内容はインターネット上の誰でも見られます。個人情報や秘密情報はアップロードしないでください。
反映には数分かかることがあります。
