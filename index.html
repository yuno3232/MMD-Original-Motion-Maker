03 対応ボーン階層

指定されたボーン構成を確認できます。左右の腕・指・目のボーンを含めています。★・☆は元の命名メモとして表示しています。

センター／上半身／頭部
センター └─ 上半身 ├─ 首 │ └─ 頭 │ ├─ 目_L★ ─ 目先_L☆ │ ├─ 目_R★ ─ 目先_R☆ │ ├─ 両目 ─ 両目先☆ │ ├─ _dummy_目_L / _dummy_目_R │ ├─ 頭先☆ │ ├─ _shadow_目_L★ │ └─ _shadow_目_R★ ├─ 肩_L ─ 腕_L ─ ひじ_L ─ 手首_L ─ 指ボーン └─ 肩_R ─ 腕_R ─ ひじ_R ─ 手首_R ─ 指ボーン 下半身 ├─ 足IK_L └─ 足IK_R

注意：ボーン名はモデルごとに異なります。現在の生成モーションは標準的なMMDボーン向けです。独自名の目・指・IKボーンを正確に動かすには、モデル側のボーン名とIK構造に合わせた調整が必要です。
